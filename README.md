# 🚀 Featured Projects

## 🌐 SyncSpace — Real-time Video Calling & Chat App

A **full-scale real-time communication platform** for language exchange with chat, video calls, screen sharing, and customizable UI themes.

🔗 **Live Demo:**  
👉 https://syncspace-vywz.onrender.com/login

### ✨ Highlights
- 💬 Real-time chat with typing indicators & reactions
- 🎥 1-on-1 & group video calls + screen sharing
- 🌍 Language exchange matching system
- 🎨 32 unique UI themes
- 🔐 Secure authentication using JWT
- 🧠 Global state management with Zustand
- 🔄 Stream API integration for chat & video

### 🛠 Tech Stack
- **Frontend:** React, Vite, TailwindCSS  
- **Backend:** Node.js, Express, MongoDB  
- **Realtime:** Stream API  
- **State:** Zustand  
- **Data Fetching:** TanStack Query  
- **Auth:** JWT  
- **Deployment:** Render
